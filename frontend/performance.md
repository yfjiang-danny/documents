# 性能面试考点

1. 基础理论

- 为什么需要性能优化？
  用户体验（加载速度慢影响用户留存和转化）
  SEO（搜索引擎会考虑页面加载速度）
  成本（流量消耗、服务器带宽）
- 性能瓶颈识别：
  如何定位性能问题？（使用浏览器开发者工具、Chrome Lighthouse、WebPageTest 等）
  常见的瓶颈有哪些？（网络、渲染、JavaScript 执行等）

2. 性能优化策略

- 资源优化：
  代码优化： 代码压缩、代码分割、Tree Shaking、懒加载/按需加载
  图片优化： 压缩图片、使用现代图片格式（如 WebP）、响应式图片、懒加载
  字体优化： 使用 WOFF2/WOFF 格式、字体子集化、使用系统字体
  其他资源： 压缩 CSS、JavaScript、使用 CDN
- 网络优化：
  减少 HTTP 请求： 合并文件、雪碧图、内联 SVG
  TCP 优化： HTTP/2 和 HTTP/3 协议、域名分片
  缓存策略： HTTP 缓存（强缓存、协商缓存）、Service Worker
- 渲染优化：
  CSS 优化： 减少重排（reflow）和重绘（repaint），使用 will-change 属性
  JavaScript 优化： 避免长时间运行的脚本、使用 requestAnimationFrame 进行动画渲染、事件委托、代码防抖和节流
  预加载和预渲染： link rel="preload"、link rel="prefetch"、预渲染
- 服务端渲染（SSR）、预渲染、静态站点生成（SSG）等： 比较它们在不同场景下的适用性和优缺点

3. 案例分析与实践
   项目经历： 描述你在项目中遇到的性能问题，以及你是如何解决的。
   实际操作： 面试官可能会让你现场分析一个网页的性能问题，并给出优化建议。
   工具使用： 要求你现场演示如何使用开发者工具分析性能。
   面试准备建议
   扎实基础： 熟练掌握前端性能优化相关的知识点。
   深入实践： 准备好项目中的实际案例，能够清晰地描述遇到的问题、解决方案和最终效果。
   工具熟练： 熟练使用浏览器开发者工具，特别是 Performance 和 Network 面板。
   了解工具： 了解一些常用的前端性能检测工具，如 Lighthouse、PageSpeed Insights 等。
   灵活回答： 能够结合不同场景，灵活运用各种优化手段，并分析它们的优缺点。

4. 性能指标

- 首次内容绘制（First Contentful Paint，FCP）： 页面首次绘制文本、图片或非空白内容的时刻。
- 首次有效绘制（First Meaningful Paint，FMP）： 页面主要内容已经渲染出来的时刻。
- 首次交互时间（Time to Interactive，TTI）： 页面完全可交互的时间，即页面上的所有 JavaScript 代码都已完成加载和执行。
- 最大内容绘制（Largest Contentful Paint，LCP）： 页面最大内容元素（如图片或文本块）加载完成的时间。
- 首字节时间（Time to First Byte，TTFB）： 浏览器从发起请求到接收到服务器响应的第一个字节所花费的时间。
- 完全加载时间（Load Time）： 页面所有资源（包括图片、样式表、脚本等）完全加载完成的时间。
- 交互时间（Interaction Time）： 用户与页面交互的时间，如点击、滚动等。
- 资源大小： 页面资源的大小，包括 HTML、CSS、JavaScript、图片等。
- 资源数量： 页面资源数量，包括请求的次数。
- 资源加载时间： 每个资源加载所需的时间。
- 资源缓存： 资源是否被缓存，以及缓存的策略。
- 资源压缩： 资源是否被压缩，以及压缩的比例。
- 资源优化： 资源是否进行了优化，如图片压缩、代码压缩等。
- 资源加载顺序： 资源加载的顺序，以及是否按照优先级加载。
- 资源依赖： 资源之间的依赖关系，以及是否按需加载。
- 资源预加载： 资源是否进行了预加载，以及预加载的策略。
- 资源懒加载： 资源是否进行了懒加载，以及懒加载的策略。
- 资源缓存策略： 资源缓存的时间、大小、类型等。
- 资源压缩策略： 资源压缩的类型、比例、算法等。
- 资源优化策略： 资源优化的手段、工具、方法等。

1. 性能优化

- 优化页面加载速度： 通过减少 HTTP 请求、优化资源大小、使用 CDN、启用 HTTP/2 等手段来提高页面加载速度。
- 优化渲染性能： 通过减少重绘和回流、使用 CSS 动画代替 JavaScript 动画、使用虚拟 DOM 等手段来提高页面渲染性能。
- 优化 JavaScript 执行： 通过减少 JavaScript 代码量、使用异步加载、使用 Web Workers 等手段来提高 JavaScript 执行性能。
- 优化资源加载： 通过使用缓存、预加载、懒加载等手段来优化资源加载。
- 优化用户体验： 通过优化页面布局、交互设计、动画效果等手段来提高用户体验。
- 优化 SEO： 通过优化页面结构、内容、关键词等手段来提高搜索引擎排名。

2. 性能监控

- 使用浏览器的开发者工具进行性能监控： 可以使用 Chrome DevTools、Firefox Developer Tools 等工具来监控页面的性能，包括加载时间、渲染性能、JavaScript 执行时间等。
- 使用第三方性能监控工具： 可以使用 Google Analytics、New Relic、AppDynamics 等工具来监控页面的性能，包括用户访问量、页面加载时间、用户交互时间等。
- 自定义性能监控： 可以使用 JavaScript 来自定义性能监控，包括记录页面加载时间、记录用户交互时间、记录资源加载时间等。

3. 性能优化工具

- Lighthouse： Google 提供的一个开源工具，用于评估网页性能、可访问性、最佳实践等方面。
- WebPageTest： 一个在线工具，用于测试网页的性能，包括加载时间、渲染性能、JavaScript 执行时间等。
- YSlow： Yahoo 提供的一个开源工具，用于评估网页性能，包括减少 HTTP 请求、优化资源大小、使用 CDN、启用 HTTP/2 等方面。
- PageSpeed Insights： Google 提供的一个在线工具，用于评估网页性能，包括减少 HTTP 请求、优化资源大小、使用 CDN、启用 HTTP/2 等方面。
- Webpack Bundle Analyzer： 一个 Webpack 插件，用于分析 Webpack 打包后的文件大小和依赖关系，帮助开发者优化资源加载。

4. 性能优化策略

- 减少 HTTP 请求： 通过合并文件、使用雪碧图、使用 CDN 等技术减少 HTTP 请求的数量。
- 压缩资源： 通过使用 Gzip、Brotli 等压缩算法压缩资源文件，减少传输大小。
- 使用缓存： 通过设置合适的缓存策略，减少重复请求，提高页面加载速度。
- 优化图片： 通过使用合适的图片格式、压缩图片大小、使用懒加载等技术优化图片加载。
- 使用 CDN： 通过使用 CDN，将资源部署到离用户更近的服务器，减少资源加载时间。
- 优化 CSS 和 JavaScript： 通过使用 CSS 预处理器、模块化、压缩代码等技术优化 CSS 和 JavaScript 的加载和执行。
- 优化页面布局： 通过使用合适的布局方式、减少不必要的嵌套、使用 CSS Flexbox 和 Grid 等技术优化页面布局。
- 优化 SEO： 通过使用合适的标题、描述、关键词、图片标签等技术优化搜索引擎优化（SEO）。

5. 性能优化实践

- 使用 Webpack 进行打包优化： 通过使用 Webpack 的代码分割、懒加载、压缩等技术，优化 JavaScript 和 CSS 的加载和执行。
- 使用 Service Worker 进行离线缓存： 通过使用 Service Worker，将资源缓存到本地，提高页面加载速度和离线访问能力。
- 使用 React 或 Vue 等现代前端框架： 通过使用 React 或 Vue 等现代前端框架，可以更方便地实现组件化、状态管理、路由管理等功能，提高开发效率和页面性能。
- 使用 PWA（渐进式 Web 应用）： 通过使用 PWA 技术，可以提供类似于原生应用的体验，提高用户粘性和页面性能。
- 使用性能监控工具： 通过使用性能监控工具，可以实时监控页面性能，及时发现和解决问题，提高用户体验。

1. 性能优化的重要性

- 提高用户体验： 性能优化可以减少页面加载时间，提高页面响应速度，从而提高用户体验。
- 提高搜索引擎排名： 性能优化可以减少页面加载时间，提高页面响应速度，从而提高搜索引擎排名。
- 降低服务器负载： 性能优化可以减少 HTTP 请求，减少资源加载时间，从而降低服务器负载。
- 提高开发效率： 性能优化可以帮助开发者更好地理解页面结构和资源加载，提高开发效率和代码质量。

2. 性能优化的目标

- 减少页面加载时间： 通过优化资源加载、减少 HTTP 请求、使用缓存等技术，减少页面加载时间。
- 提高页面响应速度： 通过优化 JavaScript 和 CSS 的加载和执行、使用合适的布局方式等技术，提高页面响应速度。
- 提高用户体验： 通过优化页面布局、使用合适的图片格式等技术，提高用户体验。
- 提高搜索引擎排名： 通过优化 SEO、减少页面加载时间等技术，提高搜索引擎排名。
- 降低服务器负载： 通过优化资源加载、减少 HTTP 请求等技术，降低服务器负载。

1. 性能优化的方法

- 优化资源加载： 通过使用 CDN、压缩图片、使用 HTTP/2 等技术，优化资源加载。
- 优化 JavaScript 和 CSS： 通过使用模块化、压缩代码、使用 CSS 预处理器等技术，优化 JavaScript 和 CSS 的加载和执行。
- 优化页面布局： 通过使用合适的布局方式、减少不必要的嵌套、使用 CSS Flexbox 和 Grid 等技术，优化页面布局。
- 优化 SEO： 通过使用合适的标题、描述、关键词、图片标签等技术，优化搜索引擎优化（SEO）。
